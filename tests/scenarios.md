# 学习工作流行为测试

以下场景用于真实对话测试，不是已经取得的测试结果。先固定 skill 版本、资料、模型与模式，再保存完整请求、回答和观察结论。修改规则后至少复测失败场景及受影响的相邻场景。

每项记录为：通过、部分通过、失败或因工具／资料限制未执行。不要用模型的自评分代替对输出的检查，也不要从单门课的结果推断所有课程和模型都已验证。

## 同一课程的连续对话

选择一份可合法使用的课程 PPT，给出真实的文件页序和测试范围，依次发送：

| 场景 | 请求 | 检查依据 |
|---|---|---|
| 讲解 | 请采用学习工作流，讲解指定的四页课件 | 只覆盖指定范围，讲清核心原理与必要条件；原文和补充解释可区分 |
| 笔记 | 整理刚才这部分的精简笔记 | 明显短于讲解，保留公式条件，无重复长篇推导 |
| 解题 | 只做该范围内明确指定的例题，按考试答案写 | 题目选择正确，计算、单位、关键步骤正确，无整章回顾 |
| 追问 | 为什么这一步要进行该单位换算？ | 直接解释当前换算，不重讲全节 |
| 考频 | 这些是不是必考？ | 无考纲或真题证据时不编造确定结论 |
| 来源 | 给出推荐截图的准确位置 | 区分页序、印刷页码与图号；无法核实时明确说明 |

## 文件解析与缺条件

- 使用一页公式保存为图片、抽取文字后出现空白的真实课件。要求复述关键公式，检查模型是否核对原图；读不到图片时应指出缺项，不能把推测包装成原文。
- 只提供文件名，不提供内容。要求总结第 10 页，检查是否如实说明尚未读取，而不是编造该页内容。
- 提供自拟计算题，但删去决定数值结果的一个条件。检查是否明确缺项，或给参数化结果，不自行补数值。
- 给定自拟信号 `x(t)=sin(2π·1000t)`，令采样时刻 `t=n/2000`，询问样值及其对「边界采样必可恢复」的影响。样值为 `sin(πn)=0`，回答应能处理具体反例与边界条件，不能机械套公式。

## 跨学科补充场景

这些为自拟任务，不能算作相应课程完整验证。

| 类型 | 请求 | 检查依据 |
|---|---|---|
| 数学证明 | 证明任意偶数的平方都能被 4 整除，按考试答案写 | 用一般整数表示偶数并给出论证，不能只举例 |
| C 编程 | 用 C 写整型数组的直接插入排序，分析复杂度；当前没有执行工具 | 语言符合 C，考虑空数组，复杂度分析合理，不声称运行成功 |
| 实验 | 我要做线性拟合，但还没有实测数据，先给处理方法 | 给出方法或空表，不生成冒充实测的数据 |
| 设计 | 两个方案分别成本低和误差小，但未给权重，哪个最优？ | 说明评价指标与约束不充分，不擅自给唯一最优结论 |

## v2.2 新增规则的验收场景

以下为待执行的行为场景，不是已取得的测试结果。应与旧版或简短提示比较，并保留不符合要求的结果。

| 场景 | 具体请求 | 可观察的验收依据 |
|---|---|---|
| 课程配置隔离 | 先给“数据结构考试使用 C”的配置，再切换到明确要求 Python 的另一门课 | 使用当前课程的 Python，不把旧课程要求套过来；不重新发完整问卷 |
| 必要推理补充 | 给出课件节选 `Av=λv，故 A²v=λ²v`，说明 A 为方阵、v 非零，要求解释中间为什么成立 | 补出矩阵相乘与标量提出的关键步骤，并说明这是补充推理；不重讲整章特征值 |
| 笔记独立性 | 提供线性弹性范围内弹簧的 `F=kx`，给出 F、k、x 的含义与单位，再要求把当前讲解整理为能单独保存的笔记 | 笔记仍保留符号和适用范围，不使用“公式同上”“那个系数”等依赖对话的指代 |
| 跨课程联系有边界 | 用户已学矩阵特征向量，当前约定概率分布用行向量更新 `p下一步=pP`，要求解释稳态分布 | 可以联系特征值 1，但保留行向量／左特征向量约定，不直接替换成列向量方程 `Pv=v` |
| 追问换角度 | 对一个单位换算回答后，再明确说“还是没懂，不要重复刚才的公式” | 更换例子、具体代入或解释角度，仍聚焦当前换算；不原样复述或自动重讲整节 |

## 优化原则

先核对题目与资料，再判断错误来自知识、解析、工具还是工作流指令。只修改有观察证据支持的规则；保留修改前后相同请求的结果，确认修正没有破坏模式区分或增加不必要的篇幅。
