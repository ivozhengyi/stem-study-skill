# 真实课件测试记录 · 2026-10-25

## 范围与方法

- 使用 ChatGPT 网页端，通过 Safari 的原生 computer use 操作真实聊天框。
- 新建一个专用测试项目，分别建立基线聊天与更新版复测聊天。
- 使用一份 56 页的《通信原理》第五章 PPTX，测试实际幻灯片第 8～11 页的低通抽样定理。
- 基线版本为 v2.0；更新版本为 v2.1.0。除附件名称外，讲解复测沿用相同请求。
- 界面显示强度为 High，未显示可核实的具体底层模型版本，因此不将结果归属于某个指定型号。
- 项目使用默认记忆，同项目的新聊天可能受到既有背景影响；这是一次实际使用检查，不是隔离盲测或统计性模型评测。
- 共执行 9 次请求：基线四种学习任务、一次反馈审阅、更新版讲解与笔记、一次图像来源核对，以及最终版原图定点复测。

课件仅供本次私有测试使用，不随仓库发布。原始回答、浏览器截图与课件抽取内容也不公开。以下仅记录必要的观察和规则变化。

## 基线观察

| 场景 | 实际观察 | 判断 |
|---|---|---|
| 讲解第 8～11 页 | 覆盖指定范围，例题计算得 0.5 ms；有一处将“奈奎斯特抽样速率”称作“奈奎斯特频率” | 需要修正术语一致性 |
| 精简笔记 | 明显短于讲解，但仍包含多个中间推导式和具体例题步骤 | 模式切换有效，筛选标准仍可改善 |
| 只解第 11 页示例 | 给出必要公式、代入、单位及 0.5 ms 结果，没有附加考点回顾 | 满足当前样本要求 |
| 追问角频率与 Hz 换算 | 围绕每周期 2π 弧度解释换算，没有重讲整节 | 满足当前样本要求 |

## 反馈核验与修改

完成四轮测试后，向同一聊天请求具体改进反馈，再对照实际输出与原始资料核实。没有将自评分当作验收结论。

| 观察或建议 | 处理 |
|---|---|
| 相近专业术语混用 | 增加准确名称、定义和符号一致性的要求 |
| 多个补充例子、路线图与总结存在功能重复 | 修改讲解规则，补充内容须解决明确难点，减少重复 |
| 笔记仍保留非必要的中间推导与完整数值过程 | 增加“记忆、调用、区分易错概念”的逐项筛选标准 |
| 大部分知识点都标最高星级 | 允许在小节层面统一分级，按需说明学习要求，避免强行制造等级差异 |
| 课件文字抽取后公式位置留白 | 通过本地文件检查确认图片公式存在，增加解析完整性检查与来源区分 |
| 模型反馈怀疑原课件某公式缺少下标 | 检查原始公式图片后确认下标存在，未采纳“课件笔误”判断，也未据此增加规则 |

## 更新版复测

| 检查项 | 复测观察 | 结论 |
|---|---|---|
| 术语 | 新聊天沿用“奈奎斯特抽样速率”，未重复基线中的错误称谓 | 当前样本改善 |
| 星级分层 | 讲解中的定理与图解标为核心，数学推导和例题标为重要；笔记也有分层 | 当前样本改善 |
| 笔记筛选 | 删除冲激序列定义与抽样输出的中间式，保留频谱复制最终式、条件及简短计算 | 当前样本改善，仍保留短例题 |
| 补充内容密度 | 减少额外混叠数值例子，但仍增加外部图片和交互示意 | 部分改善，不能认定所有冗余均已消除 |
| 图像来源 | 发现外部搜索图片紧接课件图号说明，来源容易混淆；定点询问后模型承认未从 PPT 提取 | 新发现的问题，继续修订 |

据此在最终版增加“原图与补充图分开”的规则：不能用搜索结果替换课件原图，外部或自绘图须就近标明性质与来源，无法展示原图时可引用已核实的位置。

随后在同一复测聊天上传最终版，再请求只处理实际第 10 页图示。模型明确说明从课件提取原图，并返回六联图。打开其图像预览后，与原 PPT 中嵌入的六联图进行视觉对照，布局、曲线、符号及子图标记相符。该定点复测满足了当前请求的来源区分要求；它受已有纠错上下文影响，不能作为独立泛化证据。

## 结果限制

此次测试只覆盖单门课程的一小段内容、一个 ChatGPT 网页环境和有限对话。它能发现具体的指令执行问题，不能证明所有理工科课程或所有大语言模型均已验证，也不能保证修订后的规则在每次生成中都稳定生效。

[通用测试场景](scenarios.md) 还包含证明、编程、实验与设计任务；未执行的场景不计入本次结果。
