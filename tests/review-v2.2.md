# v2.2 优化审视 · 2026-10-26

结论：五项新增内容有合理的使用价值，适合合入；它们把已有原则转为更具体的处理方式，尚不能证明学习耗时或成绩已有改善。

本次进行了文本差异、规则冲突、格式和入口同步检查，没有重新进行 ChatGPT 行为实测。此前的 9 次真实请求属于 v2.0 与 v2.1，不能作为 v2.2 新规则已验证的证据。

## 逐项决定

| 提案 | 判断 | 合入方式与边界 |
|---|---|---|
| 可选课程配置 | 值得保留，主要改善长期复用 | 将分散的课程偏好变为可复制配置；始终可选，当次要求优先，不跨课程套用 |
| 补足必要逻辑桥梁 | 有价值，但与原来的关键步骤要求部分重叠 | 明确课件跳步时补最短推理，不变成逐项补全全部证明 |
| 跨课程知识迁移 | 有条件的辅助价值 | 只借用用户明确掌握、能直接解释当前卡点的知识；不固定添加联系段落，保留条件差异 |
| 笔记独立可复习 | 本次最值得保留的改进之一 | 即使脱离原对话，符号、条件和方法前提仍可辨认；不因此恢复完整讲解 |
| 定位追问卡点并换角度解释 | 本次最值得保留的改进之一 | 多次不理解时改变解释方式；不向用户输出固定分类，也不靠无限加长代替定位问题 |

保留现有段落空行，未采用提案中压缩 Markdown 空行的变化。该变化不改善辅导行为，却使文件更难审阅。原始 v2.2 提案保留在本地，发布的是整合后的维护入口。

## 价值究竟在哪里

这份 skill 的主要价值是把反复使用的学习约定保存下来：如何沿着资料学习、什么时候精简、如何只回答卡点，以及怎样诚实处理来源和工具限制。对经常用 AI 学习多门课程、不断重复要求“别展开”“给考试步骤”“笔记再短一点”的用户，这是一种值得复用的工作方式。

它提供的核心增益在于减少重复提示、输出返工和格式切换。它没有增加模型本身的学科知识、文件识别或计算能力，也没有使不可靠的模型变成可靠的答案来源。强模型本来可能就能完成其中许多要求，因此应与简短提示词比较，不能仅凭规则更完整就认定收益更大。

## 适用对象

- 已有课程课件、教材节选或习题，希望用 AI 辅助持续自学、答疑和考前复习的大学生。
- 同时学习多门课，希望复用偏好，又需要区分课程符号、语言和考核要求的人。
- 愿意依据原资料核查重要结论，并能提供当前卡点的人；含理工科课程适配。

对于偶尔问一道题、已有成熟提示模板，或所用工具已经能稳定保持同等约定的用户，增加整份工作流的收益可能较小。没有课程资料时仍可回答自足问题，但不能发挥“沿着本课程资料学习”的主要优势。

## 当前不足

1. **规则长度有成本。** 维护源文件由 18,554 字节增至约 20 KB。载入、阅读、维护和模型遵循均有成本；体积不等于实际 token 数，不能据此估算模型费用。后续应优先合并重复规则，而非不断增加条款。
2. **遵循程度仍不稳定。** 规则可以要求不猜来源、分清术语，但不能保证模型每次做到。先前有限实测中，修正一处问题后仍发现了图片来源问题。
3. **输出质量与学会程度不同。** 一份清晰笔记只能证明材料便于阅读，不能证明用户能独立解题。当前自测和引导需要用户主动提出，掌握程度还没有闭环验证。
4. **效果证据有限。** 既有测试是单课程、单平台、受记忆与纠错上下文影响的使用检查；没有无 skill 对照，没有跨模型重复测试，也没有时间或学习成绩实验。

## 怎样验证是否真的省时

用难度相近的新章节，在同一模型和资料条件下比较三种方式：普通提问、简短的三模式提示、完整 skill。交替安排测试顺序，并保留失败及返工记录。

记录用户实际操作时间、纠正回答的轮数、重新整理笔记的时间，以及重要条件和来源错误。把核对与纠错的耗时计入总时间，不能只比较回答字数或生成速度。再用短小的闭卷题与迁移题检查理解，避免把阅读顺畅当成学会。

这些是后续验证建议，本次没有执行，不据此给出节省小时数、百分比或提分承诺。

## 建议的后续优先级

先验证新增规则能否减少真实返工，再考虑精简便携版与按需的掌握度自测。更多模式、更多固定输出栏目和逐科扩张规则都应以真实失败或学习需求为依据。
