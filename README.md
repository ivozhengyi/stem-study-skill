# Course Study Skill

**把整理资料的时间，留给真正学会。**

一次配置，复用「讲解、笔记、做题」三种模式，减少每次重写提示词、逐页筛选重点、把长回答压缩成复习笔记的时间。把课件、教材和习题交给 AI，直接开始当前任务，追问时聚焦卡点。

适合手头已有课件、教材或习题，希望用 AI 辅助日常自学、课后答疑和考前复习的大学生，尤其适合同时学习多门课、经常重复说明学习要求的人。含理工科任务适配，不绑定模型厂商，不要求安装插件。

当前版本为 **v2.2.0**：加入可复用的课程配置、必要推理补充、按需知识联系、可独立复习的笔记，以及卡住后换角度解释的规则。[v2.2 审视记录](tests/review-v2.2.md) 说明了各项改动的价值、采用条件和验证边界。

## 直接开始

下载 [course_study_skill.md](course_study_skill.md)，将它与当前需要学习的课程资料交给你的 AI 助手，发送：

> 请采用这份学习工作流。课程是通信原理，使用我提供的课件。先讲解第 8～11 页，我对抽样定理还不熟悉。

然后可以直接接着说：

```text
整理这一节的精简笔记。
只做指定的那道题，按考试答案写。
这一步为什么要除以 2π？
先给提示，暂时不要完整答案。
```

不支持上传文件时，可以粘贴工作流正文和相关资料。支持原生 skill 的工具，可使用同内容的 [SKILL.md](SKILL.md)，按其要求放入 `course-study-workflow/SKILL.md`；是否自动加载由所用平台决定。

## 三种模式，各有分寸

| 模式 | 你得到什么 |
|---|---|
| 讲解 | 顺着课程资料讲清概念、推导与应用，难点展开，已掌握的基础少重复 |
| 笔记 | 保留核心定义、公式条件、典型方法与易错点，适合复习 |
| 做题 | 只处理指定题目，给出可复核的关键步骤、必要图形和结论 |

追问只处理当前卡点。你也可以明确要求组合任务、逐步引导或自测，不必记住专用指令。

## 课程不同，方法也不同

这份工作流按任务选方法，覆盖数学证明、物理与工程计算、概率统计、编程算法、化学材料、生命地学、工程作图、实验测量和开放设计。

- 证明题保留关键论证，不能拿几个例子代替证明。
- 计算题关注模型、单位、方向、边界条件和结果合理性。
- 编程题遵守指定语言与环境，区分写过代码和实际运行过代码。
- 实验题区分实测值、理论值与模拟值，缺数据时不补造记录。
- 开放设计说明目标、约束与取舍，不把可行方案说成唯一最优解。

## 资料优先，结论可查

工作流要求区分资料原文、推导结论、补充解释和待核实内容。课件中的公式可能保存为图片，抽出文字后仍需检查信息是否完整。

学习重点与实际考频分开标注。没有依据，不猜页码、不预测「必考」，也不声称已运行代码或已画出尚未生成的图。

## 兼容性与验证范围

这是模型无关的自然语言工作流，不是为不同模型提供相同能力的适配程序。文件解析、视觉、绘图、代码执行、联网及上下文长度仍取决于所用模型和平台；工作流提供相应降级方式，不能保证所有模型表现一致。

已用一份真实《通信原理》PPT 在 ChatGPT 网页端建立专用项目，完成两个聊天、共 9 次请求的基线测试、反馈核验与定点复测。测试发现并推动修订了术语混用、笔记筛选、星级标注及外部图片冒充课件原图等问题；最后一项复测已返回课件嵌入原图，并经过视觉对照。详见 [真实测试记录](tests/evaluation-2026-10-25.md)。

这只是单门课程、单个平台的有限使用检查，不代表所有模型或全部理工科课程已通过验证。各项改动的实际效果和未解决限制都在测试记录中说明。

本次没有进行学习耗时的对照实验，因此不提供未经验证的节省时长或百分比。

[测试场景](tests/scenarios.md) 提供可复用的检查请求与验收依据。公开发布时只包含工作流和说明，不包含教师课件、个人对话或登录信息。

## 修改与同步

`course_study_skill.md` 是维护源文件；`SKILL.md` 是同内容的原生 skill 入口。修改源文件后运行以下命令同步，不需要额外依赖：

```sh
python3 scripts/sync_skill.py
```

该脚本仅用于维护仓库。正常使用工作流无需 Python 或命令行。
